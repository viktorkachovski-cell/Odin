# Odin Android design review

The owner approved the mobile direction on 2026-10-13 and requested coding,
testing and deployment. The Android implementation retains Odin's palette and
shared task rules.

- Open `odin-mobile-review.html` for the approved, self-contained interactive
  proposal. It uses fictional data and makes no network requests.
- Open `audit.html` or `audit.md` for the original source-grounded audit.
- See [`design-qa.md`](design-qa.md) for implementation comparisons and limits.
- See [`../docs/android-ui-acceptance-2026-10-14.md`](../docs/android-ui-acceptance-2026-10-14.md)
  for checks, failures, release evidence and remaining device work.

The HTML is a historical design reference, not the production Android client.
Its original baseline renders the pre-change Android components in a browser
with local adapters; its proposal simulates interactions. Native implementation
evidence is saved separately in `evidence/native-*.jpg`.
